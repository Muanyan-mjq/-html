# 3D 粒子爱心

一个纯前端的 3D 粒子爱心页面，零依赖、零构建，打开即用。

## 在线预览

<https://muanyan-mjq.github.io/-html/>

## 特性

- **3D 爱心**：约 9000 个发光粒子构成的完整立体爱心，持续缓慢旋转
- **开场动画**：粒子从四周散落状态聚拢成爱心
- **交互动画**：鼠标拖动 / 手机滑动旋转，带惯性甩动，松手后逐渐停下
- **心跳律动**：周期性双脉冲（lub-dub）缩放，同步扩散光晕圆环
- **粒子细节**：独立闪烁、表面呼吸起伏、正面高光星点、速度越快拖尾越长
- **氛围**：流星划过、漂浮星尘、暗角、渐变流光文字
- **文字**：I LOVE YOU / 愿每一次心跳·都有回响 / TO Hikoy

## 使用

直接双击 `index.html` 即可在浏览器打开（离线可用），或部署到任意静态托管服务。

## 技术说明

- 纯原生 HTML + Canvas 2D + JavaScript
- 爱心轮廓由经典参数方程生成：

  ```
  x = 16sin³t
  y = 13cost − 5cos2t − 2cos3t − cos4t
  ```

- 3D 形体为对称饱满结构，粒子按深度着色（洋红 → 玫红 → 深红），加法混合叠加发光
- 粒子精灵预渲染 + 视口自适应，移动端可用

## 自定义

| 想改什么 | 位置 |
| --- | --- |
| 文字内容 | HTML 中 `.title` / `.sub` / `.to` |
| 心跳速度 | JS 中 `PERIOD`（默认 1150ms） |
| 粒子数量 | JS 中 `POINTS`（默认 9000） |
| 主色调 | JS 中 hue 计算（范围 320–362）与 sprites 生成 |
| 旋转 / 滑动灵敏度 | `pointermove` 中的 `0.0055` / `0.0045` 系数 |
